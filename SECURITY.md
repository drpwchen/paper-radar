# Security

Please report vulnerabilities privately through GitHub: use the **Security** tab of this repository and choose **Report a vulnerability** (private vulnerability reporting). Please do not open a public issue for security problems.

This project handles API tokens (Cloudflare, ntfy, optional Groq) and can serve a private page that records your reading actions. If you find a way tokens could leak, or a way the private site could be reached without access control, that is in scope. See the "Security & permissions before you self-host" section of the README for the expected setup.

這個專案會用到 API token（Cloudflare、ntfy、選用的 Groq），也可能架一個記錄你閱讀動作的私密網頁。發現漏洞請從本 repo 的 **Security** 分頁選 **Report a vulnerability** 私下通報，不要開公開 issue。
